# Render archive (notes from director Ruth Calloway, emailed 2024)

The original animation project files are not at the lab. When we wrapped, I kept a set of LTO-4 tapes with the Maya scenes, rigs, textures and the comp files. They are in my garage in Altadena. I have never tried to read them.

The film was rendered at 2K. A true 4K version would mean re-rendering from these files, if they still read and if the software versions can be rebuilt. Otherwise it's an upscale of the 2K DPX.

I don't believe I own the files; they were made for Lantern Films. I'd want to be involved in any restoration.
